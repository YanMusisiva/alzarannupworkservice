# **App Name**: ANN: Local Buzz

## Core Features:

- Announcement Creation: Allow businesses to create new announcements with text, images, and links.
- Automatic Expiration: Automatically expire and remove posts after one week.
- Location-Based Feed: Display announcements based on the user's specified city during registration.
- City-Based Registration: Require users to register with their city to tailor announcement feeds.
- Image analysis and moderation: Analyze each user submitted image using a tool that blocks malicious images.

## Style Guidelines:

- Primary color: Warm orange (#FF7F50) for a friendly, inviting feel.
- Background color: Desaturated light orange (#FAEBD7). This is 20% saturation with the hue held constant.
- Accent color: Teal (#3CB371) to complement the orange and add contrast.
- Body and headline font: 'PT Sans' for a modern and accessible look.
- Use simple, clear icons to represent announcement categories and actions.
- Clean, card-based layout for easy browsing on all devices.
- Subtle animations for transitions and feedback.
